# Wizard Duel

**Wizard Duel** — браузерная игра, в которой игрок рисует магические руны указательным пальцем перед веб-камерой. Приложение распознаёт движение руки в реальном времени, превращает руну в заклинание и показывает результат в дуэли. Видео обрабатывается в браузере и не отправляется на сервер.

**Рабочая версия:** [admit-hackathon-sigma.vercel.app](https://admit-hackathon-sigma.vercel.app/). После входа откроется лобби: [прямая ссылка на лобби](https://admit-hackathon-sigma.vercel.app/lobby.html). Для игры через камеру разрешите браузеру доступ к ней. Игроку не нужно ничего устанавливать.

## Как играть

1. Создайте аккаунт или войдите, затем выберите тренировку с ботом. Также доступна приватная дуэль с другом по коду комнаты.
2. Нажмите **«Включить камеру»**. Держите руку в кадре и вытяните указательный палец, согнув остальные три пальца.
3. Нарисуйте руну в воздухе указательным пальцем. Для завершения раскройте ладонь и поверните её к камере.
4. Следите за подсветкой руки, нарисованной траекторией и карточкой результата. Успешная руна применяет заклинание: меняет здоровье, ставит щит или задерживает атаку противника.
5. Дуэль заканчивается победой одного из игроков. Кнопка **«Начать заново»** запускает новую тренировку.

Перед дуэлью можно пройти [обучение](https://admit-hackathon-sigma.vercel.app/tutorial.html): семь уроков знакомят с рунами и завершаются защитой от атаки на время. В обучении доступны камера и рисование мышью или касанием. В дуэли кнопки заклинаний также служат запасным способом управления; основной сценарий использует веб-камеру.

## Движения и действия

Сначала игрок принимает позу для рисования — вытягивает указательный палец. Затем одним движением рисует руну и раскрывает ладонь, чтобы применить распознанное заклинание.

| Руна | Действие |
| --- | --- |
| Прямая линия | **Искра** — быстрая атака, 7 урона |
| Треугольник | **Огненный шар** — атака, 20 урона |
| Круг | **Щит** — блокирует следующий удар |
| Зигзаг | **Молния** — атака, 15 урона |
| Квадрат | **Остановка времени** — задерживает атаку противника на 1,5 секунды |
| Две соединённые треугольные петли | **Двойное пламя** — мощная атака, 45 урона |

## Режим «Ошибка»

Распознавание оценивает не только совпадение с руной. Приложение проверяет форму траектории, замкнутость, количество поворотов, направление и пропорции. Если рисунок похож на руну, но не подходит для заклинания, карточка результата на русском языке показывает, что исправить: например, приблизить конец линии к началу, сделать петлю круглее или добавить нужное число чётких поворотов. Неточное движение не применяет заклинание.

Во время рисования интерфейс также подсказывает, когда нужно согнуть остальные пальцы, раскрыть ладонь или повернуть её к камере. Если камера не видит руку, появляется подсказка о положении руки и освещении. Так игрок может исправить попытку и повторить её сразу в той же дуэли.

## Локальный запуск

Понадобятся **Node.js 22.12+**, npm и Docker с Docker Compose. Клонируйте репозиторий и откройте **два терминала в его корне**.

**Терминал 1 — API и PostgreSQL:**

```bash
cp .env.example .env
```

В созданном `.env` задайте `MAGIC_DATABASE_URL` с адресом базы **`postgres:5432`**, поскольку API запускается внутри Docker. Пароль в этой строке должен совпадать с `POSTGRES_PASSWORD`. Например:

```dotenv
POSTGRES_PASSWORD=change-this-local-password
MAGIC_DATABASE_URL=postgresql+psycopg://magic:change-this-local-password@postgres:5432/magic
```

Замените примерные пароли и `MAGIC_JWT_SECRET` своими значениями, затем запустите сервисы:

```bash
docker compose up --build
```

Миграции базы выполняются автоматически при запуске API. Проверка доступности: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health).

**Терминал 2 — браузерное приложение:**

```bash
cd web
npm ci
npm run setup
npm run dev
```

Откройте адрес, который покажет Vite (обычно [http://127.0.0.1:5173](http://127.0.0.1:5173)). Зарегистрируйте аккаунт на стартовой странице и выберите тренировку. `npm run setup` загружает модель MediaPipe и копирует WebAssembly-файлы: они нужны и для локального запуска, и при сборке деплоя, но не хранятся в Git. Камера работает на `localhost` или через HTTPS.

Если API запущен на другом адресе, задайте `VITE_API_BASE_URL` **до запуска или сборки** фронтенда. Для публичного HTTPS-деплоя этот адрес должен вести на доступный HTTPS API; локальный адрес `127.0.0.1` у посетителей сайта не подойдёт.

## Технологии и проверка

- **Фронтенд:** TypeScript, Vite, MediaPipe Hand Landmarker. MediaPipe выдаёт координаты кистей; правила для позы, записи траектории, сопоставления с рунами и исправляющих подсказок реализованы в проекте.
- **Бэкенд:** FastAPI, PostgreSQL, WebSocket. Сервер отвечает за аккаунты, приватные комнаты, состояние онлайн-дуэли и статистику профиля. Тренировка с ботом работает локально в браузере после входа в аккаунт.
- **Обратная связь:** скелет кисти, подсветка активного жеста, траектория рисунка, карточка результата, полосы здоровья, анимация и звук. Профиль показывает результаты онлайн-дуэлей.

Проверки из каталога `web/`:

```bash
npm test
npm run build
```

Проверки бэкенда из корня репозитория:

```bash
python -m pip install ".[test]"
python -m pytest
```

Источники и лицензии звуков указаны в [описании аудио](web/public/assets/audio/README.md).
