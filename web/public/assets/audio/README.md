# Spell sound sources

`[trimmed] videoplayback.wav` is the user-supplied background music for matches and the tutorial. Its source and redistribution rights have not been documented yet; verify them before publishing a public build.

- `fireball.wav` — “Fireball” by Julien Matthey, [OpenGameArt](https://lpc.opengameart.org/content/fireball-1), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `shield.wav` — “Magic Shield” by spookymodem, [OpenGameArt](https://opengameart.org/content/magic-shield), [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/). Renamed from `Magic Shield.wav`; the source file is otherwise unmodified.
- `lightning.wav` — “lightningstrike” by MoxieCat, [OpenGameArt](https://opengameart.org/content/8-bit-platformer-sfx-0), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `spark.wav` — “spark” by BMacZero, [OpenGameArt](https://opengameart.org/content/electricity-sound-effects-0), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/).
- `time-lock.mp3` — “Time Slow” by MidFag, [OpenGameArt](https://opengameart.org/content/time-slow), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The recording is used for Time Lock.
- `twin-flare.ogg` — “magical_4” by JaggedStone, [OpenGameArt](https://opengameart.org/content/magic-spell-sfx), [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/). The recording is used for Twin Flare.

The CC BY 3.0 credit above must remain with redistributed copies of the shield effect. Playback skips quiet lead-in, caps each effect at two seconds, and adjusts volume without changing the source files. The files are used as local, user-triggered spell sounds; no audio is streamed to an external service.
